# devtools

Personal developer tooling and configuration.

- [`dotfiles/`](dotfiles/) — portable development configuration, currently
  including WezTerm + tmux, an optional framework-free zsh interactive fragment
  (completion, fzf, autosuggestions, syntax-highlighting), and a symlink
  installer (macOS, Linux, WSL).
- [`control-room/RFC.md`](control-room/RFC.md) — Control Room RFC.
